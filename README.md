# 小红书私信导出助手使用说明

小红书私信导出助手可以把网页版当前打开的聊天保存到电脑，支持文字、表情、图片、引用和分享卡片。保存后可以离线阅读、搜索、按日期筛选和输入页码跳转。

ChatGPT作品，纯AI，掺杂了可能0.1%的风味能工智人

## 安装

1. 在电脑浏览器中安装并启用 Tampermonkey。
2. 如果安装过旧版私信导出脚本，先停用旧版。
3. 打开 Tampermonkey，选择“添加新脚本”，删除默认内容。
4. 用记事本打开 `xhs-dm-exporter.user.js`，复制全部内容，粘贴到脚本编辑器中并保存。
5. 登录小红书网页版，打开要保存的具体聊天，刷新页面。

看到“小红书私信导出助手”面板即可使用。面板可以拖动，也可以收起。

## 第一次保存聊天

1. 在电脑上新建一个空文件夹。
2. 点击“选择 / 恢复备份文件夹”，选择它，并允许浏览器读写。
3. 点击“开始读取”。脚本会自动向上滚动，读取更早的消息。
4. 等本轮读取结束，或点击“停止”保留当前结果。
5. 点击“保存到文件夹”，等待保存完成。
6. 打开备份文件夹里的 `index.html` 阅读。

面板会显示当前步骤、已读取条数、用时，以及媒体保存的成功、失败和复用数量。

请保留整个备份文件夹，HTML 和旁边的 `images` 文件夹需要放在一起。一份文件夹只用于一段聊天，读取期间不要切换聊天或账号。

## 直接下载压缩包

不想选择文件夹时，读取结束后点击“下载压缩包”。

准备完成后，到浏览器下载列表查看 `小红书私信记录.zip`。下载完成后，将整个压缩包解压，再打开里面的 HTML。

记录很多时，建议使用文件夹方式。

## 以后更新新消息

1. 登录原账号，打开原聊天。
2. 选择原备份文件夹，确认恢复已有记录。
3. 点击“只更新新消息”。
4. 等待检查和保存完成。

已连接文件夹时，检查结束后会自动更新文件。没有连接文件夹时，请记得自行下载或保存结果。

## 中断后继续

连接文件夹后，脚本会定期保存读取进度。重新打开原聊天，选择原文件夹即可恢复。

也可以在“更多导出与恢复”中下载读取进度文件 `checkpoint.json`，以后使用“从进度文件恢复”继续。

进度文件不包含图片原文件，完整备份仍需保存文件夹或压缩包。

## 阅读导出的记录

- 默认打开最新一页并定位到最新消息。
- 左侧栏可以搜索、筛选发送者、消息类型和日期，也可以导出筛选结果 TXT。
- 翻页按钮在最下面；输入页码后点击“跳转”或按回车。
- 昵称和头像从页面读取，缺少昵称时显示“我 / 对方”。
- 系统消息居中显示，引用内容在正文下方单独排版。

## 常见问题

**部分图片或视频失败怎么办？**  
再次保存到同一文件夹。成功文件会尽量复用，失败项会重新尝试。

**浏览器没有允许保存怎么办？**  
重新选择文件夹并允许读写，或者改用“下载压缩包”。

**提示自动保存进度暂停怎么办？**  
当前读取结果仍在页面内，请及时下载读取进度或压缩包。

**文件夹写入超时怎么办？**  
先下载当前结果，重新打开网页后再连接文件夹。

**点击停止后会怎样？**  
正在读取的媒体会取消，已经取得的消息仍可保存。压缩包整理阶段会继续完成已有内容的打包。

**恢复失败怎么办？**  
确认选择的是 `checkpoint.json`，并在刚刷新、尚未读取其他聊天的状态恢复。

**读不到消息怎么办？**  
确认已经打开具体私信聊天，等待消息显示后重试。
