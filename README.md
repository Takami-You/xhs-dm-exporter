小红书网页版私信导出器

小红书目前可以在网页端查看私信

这是一个本地运行的浏览器脚本，可以自动加载当前联系人的历史消息，并导出成 TXT、JSON 和可以离线浏览的 HTML。

它适合备份自己的聊天记录。脚本在浏览器本地处理数据，不会把私信上传到其他服务器。

## 能做什么

- 自动向上加载当前会话的历史消息。
- 保存双方昵称、正文、时间分隔和引用消息。
- 保存行内表情、聊天图片和笔记封面。
- 识别分享笔记和分享评论卡片。
- 尝试保存私信中的直接视频和视频封面。
- 导出 TXT、JSON、联网 HTML和离线 HTML 压缩包。
- 离线 HTML 支持全文搜索和日历日期跳转。
- 导出文件自动命名为“某某的私信记录”。
- 采集过程中可以随时停止，已经取得的消息仍然可以导出。

推荐使用“离线 HTML 包（ZIP）”。解压后打开里面的 HTML，就可以像聊天记录一样浏览；图片等媒体放在旁边的文件夹中。

安装前准备

需要：

- Windows、macOS 或 Linux 电脑。
- Chrome、Edge 或其他支持 Tampermonkey 的浏览器。
- 能正常登录小红书网页版的账号。
- 下载好的 `xhs-dm-exporter.user.js` 文件。

手机浏览器不是主要支持环境，建议使用电脑。

## 方法一：使用 Tampermonkey 安装（推荐）

### 第一步：安装 Tampermonkey

1. 打开浏览器扩展商店。
2. 搜索 `Tampermonkey`。
3. 确认扩展名称和发布者无误后安装。
4. 安装完成后，浏览器工具栏会出现 Tampermonkey 图标；如果没有看到，可以在扩展菜单中把它固定到工具栏。

请只从浏览器官方扩展商店或 Tampermonkey 官方网站安装，不要使用来源不明的修改版。

### 第二步：新建用户脚本

1. 点击浏览器工具栏中的 Tampermonkey 图标。
2. 选择“添加新脚本”或“创建新脚本”。
3. 编辑器中会出现一段默认示例代码。
4. 全选并删除默认代码。
5. 用记事本或代码编辑器打开 `xhs-dm-exporter.user.js`。
6. 复制文件里的全部内容，粘贴到 Tampermonkey 编辑器。
7. 按 `Ctrl+S`，或者选择“文件 → 保存”。
8. 回到 Tampermonkey 管理面板，确认“小红书网页私信导出器”处于启用状态。

### 第三步：确认脚本成功运行

1. 打开小红书网页版并登录。
2. 进入“消息”，打开某一个人的具体私信会话。
3. 刷新一次页面。
4. 页面右上方应出现红色标题的“小红书私信导出器 v1.3.1”面板。

如果面板挡住聊天内容，可以按住顶部红色标题栏拖动。点击右上角 `×` 只会隐藏面板，不会删除脚本。

## 开始采集

1. 确认当前打开的是你要保存的联系人。
2. 点击面板中的“快速采集”。
3. 脚本会自动滚动并加载更早的消息。
4. 面板会显示当前轮数、消息数量、图片/表情数量、视频数量和时间分隔数量。
5. 到达顶部后，脚本还会等待一小段时间，防止网络稍慢时提前结束。
6. 显示“采集完成”后即可导出。

如果聊天记录特别多，你也可以先自己手动滚到最上方，等页面不再加载更早消息后再点击“快速采集”。脚本检测到已经在顶部时，不会先滚回底部。

采集过程中感觉已经完整，可以点击“停止”。此前取得的数据会保留。

## 导出离线 HTML 包

1. 采集完成后点击“导出离线 HTML 包（ZIP）”。
2. 浏览器会提示即将读取多少个媒体资源，点击确认。
3. 脚本会尝试保存图片、表情、头像、笔记封面、视频封面和能够识别的视频。
4. 临时下载失败的资源会自动重试，最多5次。
5. 完成后浏览器会下载“对方昵称的私信记录.zip”。
6. 找到 ZIP，右键解压到一个独立文件夹。
7. 打开文件夹内的“对方昵称的私信记录.html”。

请不要只把 HTML 单独移动出去。HTML 旁边的媒体文件夹也需要保留，否则离线图片无法显示。

## 其他导出按钮

- **导出 TXT**：适合用记事本查看和搜索文字。
- **导出 JSON**：数据最完整，适合备份和以后转换格式。
- **快速 HTML（联网图）**：生成很快，但图片需要联网并且原地址以后可能失效。
- **单文件内嵌 HTML**：把成功读取的图片放进一个 HTML，使用方便，但文件可能非常大。
- **单独下载图片**：只保存识别到的媒体资源和 URL 清单。
- **DOM 诊断**：网站改版或消息识别不正确时，用来收集排查信息。

建议至少保存“离线 HTML 包”和 JSON。JSON 是以后修复或转换记录最有用的原始备份。

## 离线 HTML 怎么使用

打开导出的 HTML 后：

- 在搜索框输入文字可以搜索正文、引用、昵称、笔记标题和分享评论。
- 按 Enter 跳到下一条结果。
- 按 Shift+Enter 跳到上一条结果。
- 使用日期输入框打开日历，选择某一天后跳到当天第一处时间分隔。
- 页面顶部会显示导出时间、聊天记录时间范围和消息数量。

## 关于消息时间

小红书页面不给每一条消息提供独立时间戳。很多情况下，它只显示一条“昨天 12:34”之类的时间分隔。

因此导出的时间只能说明后面的消息属于这个时间分组，不能证明每条消息都恰好在这个时刻发送。

脚本不会凭空猜测不存在的精确发送时间。

## 图片是从缓存读取的吗

制作离线包时，脚本会先让浏览器尝试使用已有缓存。如果缓存里没有、缓存不能读取或受到跨域限制，就会根据保存下来的原始 URL 再去读取小红书的图片服务器。

所以有些图片可能直接来自缓存，有些会产生新的网络请求。原始地址已经过期或资源被删除时，即使图片刚才在页面里显示过，也存在离线保存失败的可能。

## 视频为什么可能保存失败

脚本支持常见的直接视频地址，但小红书可能使用临时 Blob、分片播放列表、隐藏接口或带时效的签名地址。遇到这些情况时，可能只能保存视频封面，或者导出的播放列表不能完全离线播放。

如果发现真实私信视频没有导出，建议保留该消息的匿名化 DOM 示例，方便以后针对真实结构适配。

## 常见问题

### 1. 没有出现导出器面板

- 确认 Tampermonkey 和脚本都已启用。
- 确认打开的是小红书网页，而不是其他网站。
- 进入某个联系人的具体聊天窗口后刷新页面。
- 检查浏览器是否阻止了扩展在该网站运行。

### 2. 采集一直在等待

可能是网页正在等待更早的历史消息。确认已经到达顶部且消息完整后，可以点击“停止”，已采集记录仍可导出。

### 3. 下载 ZIP 时显示资源失败

脚本已经自动尝试最多5次。最终失败通常表示地址过期、资源被删除、跨域限制或网络仍不可用。HTML 会尽量保留原网络地址，联网时可能仍能显示。

### 4. 导出的 HTML 图片不显示

确认已经完整解压 ZIP，并且 HTML 与媒体文件夹仍在同一个目录层级。不要在压缩包预览界面里直接打开 HTML。

## 隐私提醒

- 只导出自己有权查看和保存的会话。
- 不要未经对方同意公开聊天记录、头像、照片和视频。
- 不要把真实私信 JSON、HTML、截图、Cookie 或带签名的媒体 URL 上传到公开代码仓库。
- 分享问题样本时应删除昵称、头像、正文、消息 ID 和其他可识别信息。

这个工具的目标是帮助用户保存自己有权访问的记录，不用于绕过登录、读取他人账号或抓取无权访问的数据。
